# Projet Machine Learning Finance — Sujet F23
**CodeApogee-Nom-Groupe** | **Sujet F23 : Spread de crédit Baa et récessions**

## Description du Projet
Ce projet applique le Machine Learning (Random Forest Classifier) à la prédiction déséquilibrée des récessions américaines (NBER) à partir du spread de crédit Baa (Moody's Baa minus 10-Year Treasury Constant Maturity).
